## Fix: weapons showed twice in the hand

Holding one of the add-on's weapons showed both the new 3D model and the old flat picture at once. Now only the
3D model is drawn, in first and third person.

The 3D models were set up so they were added beside the item in the hand, instead of replacing it. Each one now
replaces its item, as the game requires.

## Install

Download `Overlord_Tomb_of_Nazarick.mcaddon` below and open it with Minecraft Bedrock 1.21.90 or newer. If the
old version is still applied to your world, replace it with this one. Saves keep working.
